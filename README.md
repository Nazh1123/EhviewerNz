# EhViewerNz

EhViewerNz 是基于 [Ehviewer_CN_SXJ](https://github.com/xiaojieonly/Ehviewer_CN_SXJ) 的 Fork.
- 发布分支: [BiLi_PC_Gamer](https://github.com/Nazh1123/EhviewerNz)
- 开发分支: [Dev_Test](https://github.com/Nazh1123/EhviewerNz/tree/Dev_Test)

## Fork 功能

### 功能与设置

- 设置菜单中为Fork各项功能加入自定义和开关设置。
- `设置 - Fork 额外功能` 集中提供对应同步设置，以供快速浏览。
- Fork 功能包含：
  - [动图播放控制](#图片浏览)、[快速翻页](#图片浏览)、[本地图片浏览器](#图片浏览)；
  - [书签订阅](#订阅聚合)、[自动获取订阅更新](#订阅聚合)；
  - [下载标签连续浏览](#下载管理)、[下载标签管理](#下载管理)、[导入本地文件夹](#下载管理)；
  - [画廊多选](#画廊搜索)、[额外信息栏](#画廊搜索)；
  - [画廊更新](#画廊详情与预览)、[提取作者](#画廊详情与预览)、[预览UI缩放](#画廊详情与预览)；
  - [原版修复](#修复)。

### 图片浏览

- “动图播放控制”，为动态 WebP 和 GIF 提供播放/暂停、播放进度条、时间显示、倍速与顺序播放功能；
  - 在屏幕底部 `25%` 区域滑动可跳转播放进度；双击该区域可切换播放与暂停；
  - “长按快进”支持 `0.1x ~ 3.0x`。长按屏幕中下区域时以该速度播放，松开恢复原本倍速；
  - 开启“顺序播放”后，动图结束时自动进入下一页；
  - 动图播放卡顿时显示警告，可点击进行降级以减少卡顿：首次降低解码分辨率 (50%*50%)，再次回退原有解码路径；
  - “从上至下”阅读方向仍使用原有解码路径。
- “快速翻页”，开启后左右区域将抑制双击逻辑而支持快速单击翻页，其余区域仍支持双击缩放。
- “长按保存”，用于快速收藏单张图片；
  - 长按翻页区域即可保存当前图片，其位置随阅读方向变化；
  - 保存成功后显示图标，可通过点击该图标撤销本次保存操作；
  - “保存后翻页”，开启后长按保存后将自动翻至下一页。
  - “手动保存路径”，用于设定长按保存的目标目录。
  - 长按保存成功后以图标提示；在提示消失前点击图标可撤销本次保存。
- “自动翻页”改为使用毫秒值，支持输入 `20 ~ 30000 ms`，或通过滑动条设置 `100 ~ 15000 ms`，默认 `2000 ms`。
- 当图片与当前屏幕方向不一致，可通过下滑手势快速切换屏幕方向。
- 可作为本地图片浏览器，打开图片文件并扫描同目录下其他图片，并保存历史记录。

### 订阅聚合

- “书签订阅”，合并所有已启用订阅的书签搜索结果，按 GID 去重后以发布时间排序。
- 在书签栏设置或 `设置 - Fork 额外功能 - 书签订阅` 中管理订阅。
- “全局订阅”，在书签订阅基础上额外合并 EH 网页自带订阅内容。
- “自动获取订阅更新”，自动获取未读画廊数量并在侧边栏中显示。
  - 可选择是否检查 EH 订阅或书签订阅；
  - 自动每小时检查一次，也可通过侧边栏“更新订阅”立即检查，并显示更新倒计时。

### 下载管理

- “下载标签连续浏览”，可在同一页面连续展示不同下载标签内的画廊；
  - 可通过下载列表菜单中的“切换列表模式”切换；
  - 标签标题显示画廊数量；点击标题可重命名标签，长按标签可直接发起对应画廊搜索。
- 已下载画廊搜索支持不区分大小写。
- 下载列表界面右下角新增按钮“归类收纳”，可通过多选已下载画廊，依次提取关键词 (Artist, Coser, Group, Title, Uploader) 进行分类并放入对应下载标签，标签支持 `#注释`。
- 下载标签管理：多选、区间选择、批量删除、批量移动、排序、删除空标签；重命名为已有标签时可直接合并。
- “导入本地文件夹”，将本地文件夹内图片导入为画廊。
- “删除本地不存在的画廊”，扫描并清理下载列表中目录缺失或空目录的记录。

### 画廊搜索

- 大缩略图模式可在封面下方显示发布时间、打码类型、下载标识与阅读进度。
- 侧边栏提供“搜索语言项”按钮，可当前搜索条件中添加或删除语言标签并进行搜索，可在设置更改不同语言标签。
- 画廊搜索页右下角按键提供：
  - “仅已下载”模式，可在搜索与列表中筛选本地已下载画廊。
  - “画廊多选”模式，可批量下载或删除选中画廊。
- 书签管理界面支持重命名和查看书签原关键词。

### 画廊详情与预览

- 画廊可复用旧画廊内容进行更新，并继承阅读进度。
- 父画廊历史，展示画廊版本链列表，并标识其中已下载画廊。
- “画廊预览立即跳转”，开启后详情页底部的预览入口将直接跳转到第二页的新内容。
- 详情页支持向左滑动快速进入画廊预览。
- 预览页面内支持双指缩放，即时调整每行图片（缩略图）数量，最多 `8` 张。
- “作者”按钮依次提取关键词 (Artist, Coser, Group, Title, Uploader) 尝试搜索；长按按钮可将完整标题拆解，以供用户选择组合进行搜索。
