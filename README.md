## 主要功能

### 图片浏览

- [“动图播放控制”](#动图播放控制)，为动态 WebP 和 GIF 提供播放/暂停、播放进度条、时间显示、倍速与顺序播放功能；
- [“漫画翻译”](#漫画翻译)，支持本地 GGUF 模型，离线 ML Kit，OpenAI 兼容 API 途径。
- [“键位设置”](#键位设置)，支持多配置自定义单击、双击、长按动作及触摸区域尺寸；将双击设为“无操作 (允许快速单击)”可实现快速单击。
- “自动翻页”，支持设定毫秒值，支持输入 `20 ~ 30000 ms`，或通过滑动条设置 `100 ~ 15000 ms`。
- “屏幕切换手势”，当图片与当前屏幕方向不一致，可通过手势快速切换屏幕方向，切换后 `3` 秒内再次执行同一手势可切回。
- 可作为本地图片浏览器，打开图片文件并扫描同目录下其他图片，并保存历史记录。

### 画廊详情

- [“书签订阅”](#书签订阅)，合并所有订阅书签的搜索结果，在单一页面中以发布时间排序，并自动更新。
- [“画廊更新”](#画廊更新)，画廊可复用旧画廊内容 (基于画廊最初版本GID 和图片pToken) 进行更新，提供仅阅读更新途径。
- 预览页面支持左滑快速进入，页内支持双指缩放，即时调整每行图片 (缩略图) 数量，最多 `8` 张。
- “作者”按钮，搜索画廊[作者关键词](#关键词提取)；长按按钮可将完整标题拆解，以供用户选择组合进行搜索。
- “回到最上方”按钮，在详情页可快速返回页面顶部。

### 下载管理

- [“下载标签连续浏览”](#下载标签)，可在同一页面连续展示不同下载标签内的画廊，并提供标签管理功能。
- 已下载画廊搜索支持不区分大小写。
- 下载列表界面右下角新增按钮“归类收纳”，可通过多选已下载画廊，根据[作者关键词](#关键词提取)进行分类并放入对应下载标签，标签支持 `#注释`。
- “导入本地文件夹”，将本地文件夹内图片导入为画廊，并提供同步文件夹功能。


### 画廊搜索

- “额外信息栏”，以缩略图(大)模式浏览时可在封面下方显示标题、发布时间、打码类型、下载标识、更新标识与阅读进度，并提供色彩高亮选项。
- 画廊搜索页右下角按键提供：
  - “仅已下载”模式，可在搜索与列表中筛选本地已下载和可更新画廊。
  - “画廊多选”模式，可批量下载或删除选中画廊。

### 功能设置

- 设置菜单中为Fork各项功能加入自定义和开关设置。
- `设置 - Fork 额外功能` 集中提供对应同步设置，以供快速浏览。

### 修复

- 修复上游版本中从画廊详情页返回下载列表后无法翻页的问题。
- 修复上游版本中点击应用图标进入应用时，可能异常进入上次页面的问题。
- 修复上游版本中特定情况中下载画廊不保存.ehviewer文件的问题。

## 功能详细说明

### 动图播放控制

- 为动态 WebP 和 GIF 提供新解码和控制播放方式，可进行播放/暂停、倍速、进度条拖动等。
- “动图控制”区域覆盖中下区域与屏幕底部指定范围，可在[键位设置](#键位设置)的动图模式中拖动分界线或输入百分比调整；区域内双击播放 / 暂停，长按倍速播放，滑动调整播放进度。
- “长按快进”支持 `0.1x ~ 3.0x` 倍速播放。在动图控制区域长按激活快进，左右移动更改倍率，松开恢复正常播放。
- 开启“顺序播放”后，动图结束时自动进入下一页。
- 动图播放卡顿时显示警告，可点击进行降级以减少卡顿：首次降低解码分辨率 (50%*50%)，再次回退原有解码路径。
- 竖直阅读方向仍使用原有解码路径。

### 键位设置

- 在 `设置 - 键位` 中，按从左到右、从右到左、从上到下三种阅读方向，分别设置普通与动图模式下 `7` 个触摸区域的单击、双击、长按动作；通过右上角按钮切换阅读方向与编辑模式。
- 支持翻页、阅读设置菜单、控制栏、缩放、图片菜单、保存图片、“开启/关闭翻译”和“切换配置”等动作；“切换配置”按配置列表顺序循环切换。
- 将区域双击设为“无操作 (允许快速单击)”，可在该区域连续快速执行单击动作。
- 触摸区域尺寸支持拖动分界线或点击线条输入百分比调整；“触摸区域一致”可同步三种阅读方向的区域尺寸。普通与动图模式共用区域尺寸，动图控制区域内的双击、长按和滑动由播放控制接管。
- 修改键位后，可通过“复制并应用到其余模式”同步当前模式中修改的动作，保存后生效；左右阅读方向同步时自动镜像两侧区域与左右翻页动作，竖直阅读方向独立同步普通与动图模式。“保存上一页”类动作不会复制到普通模式。
- 左上角“帮助”按钮显示操作提示，说明各按钮用途、快速单击设置和区域尺寸调整方式。
- 支持新建、复制、重命名、删除配置，提供默认与推荐配置；阅读设置菜单可通过下拉列表选择配置，上方快捷设置支持单击循环切换、长按选择配置。

### 漫画翻译

- 在 Android 手机设备上进行 OCR 文字识别、去字、排版。
- 提供本地 GGUF、ML Kit 和 OpenAI 兼容 API 三种翻译方式；本地模型与 ML Kit 语言包准备完成后可离线使用。
- 在 `设置 - 翻译` 中选择翻译的方式、模型、语言、去字方式、预翻译页数。
- 阅读器中长按翻译图标，可在翻译菜单中直接切换“源语言”；仅选择“自动”源语言时进行 OCR 语言识别，手动选择的源语言优先生效。
- 阅读器中可在上方快速按钮栏轻触翻译图标 或 长按菜单中开启或关闭翻译；并提供完整翻译画廊按钮。
- 默认提前翻译后续 `2` 页，可设为 `0 ~ 10` 页；完整翻译画廊可在离开阅读器后继续，并通过通知查看进度或停止任务。
- `设置 - 翻译 - 模型管理` 集中管理漫画识别模型、ML Kit 语言包和本地 GGUF，支持下载、校验、删除及漫画模型 / GGUF 文件导入；可保留多个 GGUF 并切换使用，App 已提供 HY-MT1.5-1.8B Q4_K_M 和基于 HY-MT2 1.8B Q4_K_M的日译中漫画微调模型下载途径。
- 翻译结果为以透明 png 遮罩图片形式。
- “保存译图到画廊目录”支持将已下载画廊和导入的本地文件夹的译图逐页保存至 `_translated` 文件夹。
- “删除翻译结果”，可在下载列表中多选画廊后清理译图与缓存。

### 画廊更新

- 画廊更新逻辑使用其最初版本画廊 GID(first_gid)作为版本链依据，复用最接近当前版本的旧画廊文件，在更新完成后删除所有旧画廊。
- “删除旧版本画廊”按钮，扫描拥有相同 first_gid 的画廊并保留可阅读的完整最新版本画廊，删除同版本链旧画廊。
- “版本历史”按钮，展示画廊版本链列表，并标识其中已下载画廊。
- 更新成功后，详情页提供“更新日志”，记录更新时间、新增页和删除页。
- “仅阅读更新”只浏览该次更新新增的页面，并同时显示更新页序号与原画廊页码。
- “更新记录数量”，为更新画廊保留更新历史信息，默认保留 `200` 条。

### 书签订阅

- “书签订阅”，合并所有订阅书签的搜索结果，按 GID 去重后在单一页面中以发布时间排序。
- 在书签栏设置或 `设置 - Fork 额外功能 - 书签订阅` 中管理订阅。
- “全局订阅”，在书签订阅基础上额外合并 EH 网页自带订阅内容。
- “自动获取订阅更新”，自动获取未读画廊数量并在侧边栏中显示；
  - 勾选自动检查 EH 订阅或书签订阅；
  - 自动检查间隔默认 `60` 分钟，可在 `设置 - Fork 额外功能 - 自动获取间隔` 中输入正整数分钟数；也可通过侧边栏“更新订阅”立即检查，并显示更新倒计时。
  - 长按侧边栏“更新订阅”，可直接设置自动更新开关、EH / 书签订阅检查开关与更新间隔。
- 书签订阅支持将可合并的订阅条件合并搜索；手动检查更新时会复用已有搜索结果，减少重复请求。
- 长按画廊查看其来源订阅书签。
- 长按侧边栏“书签订阅”，可直接进入书签管理。
- 可设置"书签订阅"或"全局订阅"启动页。

### 保存图片

- 用于快速本地收藏单张图片。
- 在[键位设置](#键位设置)中提供“保存当前图片”“保存当前并下一页”和“保存上一页”操作选项。
- “保存当前并下一页”，保存完成后自动翻至下一页；“保存上一页”保存当前页的前一张图片。
- 动图模式额外提供“保存上一页 (仅顺序播放时)”；横向阅读且开启动图顺序播放、存在上一页时保存上一页，否则打开图片菜单。推荐配置在动图模式的上一页侧长按默认使用此动作。
- “手动保存路径”，用于设定长按保存的目标目录。
- 保存成功后以图标提示，并区分普通保存、覆盖保存、上一页保存；在提示消失前点击图标可撤销本次保存。

### 下载标签

- “下载标签连续浏览”，可在同一页面连续展示不同下载标签内的画廊；
  - 可通过下载列表菜单中的“切换列表模式”切换；
  - 标签操作面板可重命名、搜索或同步标签 (长按)，也可展开或折叠标签内容 (单击)。
- 下载标签管理：多选、区间选择、批量删除、批量移动、排序、删除空标签；重命名为已有标签时可直接合并。


### 关键词提取

- 用于"作者"按钮，以及下载画廊的“归类收纳”。
- 首先依次尝试提取画廊Tags中的`Artist:`, `Coser:`, `Group:`标签。
- 无可用Tag时尝试从画廊标题中获取：
  - 尝试提取画廊中括号`[]` `()`内文本，并忽略特定黑名单文本；
  - 无可用括号内文本时尝试获取标题的第一个单词。
- 全部失效时使用画廊上传者作为关键词。

### 杂项

- 画廊搜索页支持长按快速下载：
    - 缩略图(大)模式且开启额外信息栏时，长按画廊右下角执行下载；
    - 详细模式，长按画廊封面执行下载。
- 画廊详细页内支持：
  - “画廊预览立即跳转”，开启后详情页底部的预览入口将直接跳转到第二页的新内容；
  - 向左滑动快速进入画廊预览，并自动判断是否跳转第二页；
  - 右上角更多菜单提供本地打开和本地路径复制按钮。
- 侧边栏提供“搜索语言标签”按钮，可在当前搜索条件中添加或删除语言标签并进行搜索；长按可修改语言标签或关闭以隐藏该按钮。
- “删除本地不存在的画廊”，扫描并清理下载列表中目录缺失或空目录的记录。
- 书签管理界面支持重命名和查看书签原关键词。
