## 主要功能

### 功能与设置

- 设置菜单中为Fork各项功能加入自定义和开关设置。
- `设置 - Fork 额外功能` 集中提供对应同步设置，以供快速浏览。
- Fork 功能包含：
  - [动图播放控制](#图片浏览)、[快速翻页](#图片浏览)、[本地图片浏览器](#图片浏览)；
  - [漫画翻译](#漫画翻译)、[翻译模型管理](#漫画翻译)；
  - [书签订阅](#订阅聚合)、[自动获取订阅更新](#订阅聚合)；
  - [画廊更新](#画廊详情与预览)、[提取作者](#画廊详情与预览)、[预览UI缩放](#画廊详情与预览)；
  - [下载标签连续浏览](#下载管理)、[画廊自动归纳](#下载管理)、[导入本地文件夹](#下载管理)；
  - [画廊多选](#画廊搜索)、[额外信息栏](#画廊搜索)；
  - [原版修复](#修复)。

### 图片浏览

- [“动图播放控制”](#动图播放控制)，为动态 WebP 和 GIF 提供播放/暂停、播放进度条、时间显示、倍速与顺序播放功能；
- [“长按保存”](#长按保存)，用于快速收藏单张图片；
- [“漫画翻译”](#漫画翻译)，支持本地 GGUF、ML Kit 与 OpenAI 兼容 API，可在阅读器中切换原图 / 译图并进行整本翻译。
- “快速翻页”，开启后左右区域将抑制双击逻辑而支持快速单击翻页，其余区域仍支持双击缩放。
- “自动翻页”，支持设定毫秒值，支持输入 `20 ~ 30000 ms`，或通过滑动条设置 `100 ~ 15000 ms`。
- 当图片与当前屏幕方向不一致，可通过下滑手势快速切换屏幕方向。
- 可作为本地图片浏览器，打开图片文件并扫描同目录下其他图片，并保存历史记录。

### 订阅聚合

- [“书签订阅”](#书签订阅)，合并所有订阅书签的搜索结果，在单一页面中以发布时间排序，并自动更新。
- “全局订阅”，在书签订阅基础上额外合并 EH 网页自带订阅内容。

### 画廊详情与预览

- [“画廊更新”](#画廊更新)，画廊可复用旧画廊内容 (基于画廊最初版本GID 和图片pToken) 进行更新，并继承阅读进度。
- 预览页面支持左滑快速进入，页内支持双指缩放，即时调整每行图片 (缩略图) 数量，最多 `8` 张。
- “作者”按钮，搜索画廊[作者关键词](#关键词提取)；长按按钮可将完整标题拆解，以供用户选择组合进行搜索。
- “回到最上方”按钮，在详情页可快速返回页面顶部。

### 下载管理

- [“下载标签连续浏览”](#下载标签)，可在同一页面连续展示不同下载标签内的画廊，并提供标签管理功能。
- 已下载画廊搜索支持不区分大小写。
- 下载列表界面右下角新增按钮“归类收纳”，可通过多选已下载画廊，根据[作者关键词](#关键词提取)进行分类并放入对应下载标签，标签支持 `#注释`。
- “导入本地文件夹”，将本地文件夹内图片导入为画廊，并提供同步文件夹功能。
- “导入本地相册 (原版)”，保留上游导入方式，将图片复制到下载目录，使用上游的封面与阅读进度处理。
- 连续浏览模式中可通过标签操作面板重命名、进入或搜索标签，并分别展开或折叠标签内容。
- “删除翻译结果”，可多选画廊后清理译图与缓存，保留原图、下载记录及模型。

### 画廊搜索

- “额外信息栏”，以缩略图(大)模式浏览时可在封面下方显示标题、发布时间、打码类型、下载标识、更新标识与阅读进度，并提供色彩高亮选项。
- 画廊搜索页右下角按键提供：
  - “仅已下载”模式，可在搜索与列表中筛选本地已下载和可更新画廊。
  - “画廊多选”模式，可批量下载或删除选中画廊。

### 修复

- 修复上游版本中从画廊详情页返回下载列表后无法翻页的问题。
- 修复上游版本中点击应用图标进入应用时，可能异常进入上次页面的问题。

## 功能详细说明

### 漫画翻译

- 在手机端识别漫画中的日文，将文字翻译后进行去字与排版；支持在线画廊、已下载画廊和本地图片，原图保持不变。
- 提供本地 GGUF、ML Kit 和 OpenAI 兼容 API 三种翻译方式；本地模型与 ML Kit 语言包准备完成后可离线使用。
- 在 `设置 - 翻译` 中选择翻译引擎、目标语言、去字方式与预翻译页数，并配置 API 地址、模型和密钥；支持测试 API 连接。
- 默认日语翻译为简体中文；本地 GGUF / API 可选德语、英语、西班牙语、法语、日语、韩语、泰语及简体中文（大陆）、繁体中文（香港 / 台湾），ML Kit 可选语言由其提供。三种方式共用日文识别模型，其他源语言的识别效果尚未验证。
- 阅读器中轻触翻译图标可开启或关闭翻译，轻触翻译进度栏可切换当前页的原图与译图；长按翻译图标可重新翻译当前页、补译缺失区域，或启动与停止整本翻译。
- 默认提前翻译后续 `2` 页，可设为 `0 ~ 10` 页；完整画廊翻译可在离开阅读器后继续，并通过通知查看进度或停止任务。
- `设置 - 翻译 - 模型管理` 集中管理漫画识别模型、ML Kit 语言包和本地 GGUF，支持下载、校验、删除及漫画模型 / GGUF 文件导入；可保留多个 GGUF 并切换使用，提供 HY-MT1.5-1.8B Q4_K_M 和基于 HY-MT2 的日译简中漫画模型下载。
- 已完成的译图可在再次打开画廊时复用；可在翻译设置中清除译图缓存，或在下载列表中多选画廊后使用“删除翻译结果”，保留原图、下载记录及模型。
- 漫画翻译版本支持 Android `8.0` 及以上的 `arm64` 设备，可与正式版并存。

### 动图播放控制

- 为动态 WebP 和 GIF 提供新解码方式；
- 在屏幕底部 `25%` 区域滑动可跳转播放进度；双击该区域可切换播放与暂停；
- “长按快进”支持 `0.1x ~ 3.0x`倍速播放。长按屏幕中下区域激活快进，左右移动更改倍率，松开恢复正常播放；
- 开启“顺序播放”后，动图结束时自动进入下一页；
- 动图播放卡顿时显示警告，可点击进行降级以减少卡顿：首次降低解码分辨率 (50%*50%)，再次回退原有解码路径；
- 竖直阅读方向仍使用原有解码路径。

### 画廊更新

- 画廊更新逻辑使用其最初版本画廊 GID(first_gid)作为版本链依据，复用最接近当前版本的旧画廊文件，在更新完成后删除所有旧画廊。
- “删除旧版本画廊”按钮，扫描拥有相同first_gid的画廊并保留可阅读的完整最新版本画廊，删除同版本链旧画廊。
- “父画廊历史”按钮，展示画廊版本链列表，并标识其中已下载画廊。

### 书签订阅

- “书签订阅”，合并所有订阅书签的搜索结果，按 GID 去重后在单一页面中以发布时间排序；
- 在书签栏设置或 `设置 - Fork 额外功能 - 书签订阅` 中管理订阅；
- “全局订阅”，在书签订阅基础上额外合并 EH 网页自带订阅内容；
- “自动获取订阅更新”，自动获取未读画廊数量并在侧边栏中显示；
  - 勾选自动检查 EH 订阅或书签订阅；
  - 自动每小时检查一次，也可通过侧边栏“更新订阅”立即检查，并显示更新倒计时；
- 书签订阅支持将可合并的订阅条件合并搜索；手动检查更新时会复用已有搜索结果，减少重复请求；
- 长按画廊查看其来源订阅书签；
- 可设置"书签订阅"或"全局订阅"启动页。

### 长按保存

- 用于快速本地收藏单张图片；
- 长按翻页区域即可保存当前图片，其位置随阅读方向变化；
- 保存成功后显示图标，可通过点击该图标撤销本次保存操作；
- “保存后翻页”，开启后长按保存后将自动翻至下一页；
- “手动保存路径”，用于设定长按保存的目标目录；
- 长按保存成功后以图标提示，并区分普通保存、覆盖保存、上一页保存；在提示消失前点击图标可撤销本次保存。

### 下载标签

- “下载标签连续浏览”，可在同一页面连续展示不同下载标签内的画廊；
  - 可通过下载列表菜单中的“切换列表模式”切换；
  - 标签操作面板可重命名、搜索或同步标签 (长按)，也可展开或折叠标签内容 (单击)。
- 下载标签管理：多选、区间选择、批量删除、批量移动、排序、删除空标签；重命名为已有标签时可直接合并。


### 关键词提取

- 用于"作者"按钮，以及下载画廊的“归类收纳”；
- 首先依次尝试提取画廊Tags中的`Artist:`, `Coser:`, `Group:`标签；
- 无可用Tag时尝试从画廊标题中获取：
  - 尝试提取画廊中括号`[]` `()`内文本，并忽略特定黑名单文本；
  - 无可用括号内文本时尝试获取标题的第一个单词；
- 全部失效时使用画廊上传者作为关键词。

### 杂项

- 画廊搜索页支持长按快速下载：
    - 缩略图(大)模式且开启额外信息栏时，长按画廊右下角执行下载；
    - 详细模式，长按画廊封面执行下载。
- 画廊详细页内支持：
  - “画廊预览立即跳转”，开启后详情页底部的预览入口将直接跳转到第二页的新内容；
  - 向左滑动快速进入画廊预览，并自动判断是否跳转第二页；
  - 右上角更多菜单提供本地打开和本地路径复制按钮。
- 侧边栏提供“搜索语言项”按钮，可当前搜索条件中添加或删除语言标签并进行搜索，可在设置更改不同语言标签。
- “删除本地不存在的画廊”，扫描并清理下载列表中目录缺失或空目录的记录。
- 书签管理界面支持重命名和查看书签原关键词。
