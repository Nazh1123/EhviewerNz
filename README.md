# EhViewerNz

EhViewerNz 是基于 [Ehviewer_CN_SXJ](https://github.com/xiaojieonly/Ehviewer_CN_SXJ) 的 Fork.

## Fork 功能

### 功能与设置

- 设置菜单中为Fork各项功能加入自定义和开关设置。
- `设置 - Fork 额外功能` 集中提供对应同步设置，以供快速浏览。
- Fork 功能包含：
  - [动图播放控制](#图片浏览)、[快速翻页](#图片浏览)、[长按保存](#图片浏览)、[自动翻页](#图片浏览)、[快捷方式栏](#图片浏览)；
  - [书签订阅](#订阅聚合)、[自动获取订阅更新](#订阅聚合)；
  - [下载标签连续浏览](#已下载画廊管理)、[下载标签管理](#已下载画廊管理)；
  - [画廊多选](#画廊搜索)、[搜索语言项](#画廊搜索)、[下载标识](#画廊搜索)；
  - [左滑预览](#画廊详情与预览)、[预览UI缩放](#画廊详情与预览)；
  - [提取作者](#画廊详情与预览)、[父画廊浏览](#画廊详情与预览)、[本地打开画廊](#画廊详情与预览)；

### 图片浏览

- “动图播放控制”，为动态 WebP 提供播放/暂停、播放进度条、时间显示、倍速与顺序播放功能；
  - 在屏幕底部 `25%` 区域滑动可跳转播放进度；双击该区域可切换播放与暂停；
  - “长按快进”支持 `0.1x ~ 3.0x`。长按屏幕中下区域时以该速度播放，松开恢复原本倍速；
  - 开启“顺序播放”后，动图结束时自动进入下一页；
  - 动图播放卡顿时显示警告，可点击作为降级入口：首次降低解码分辨率，再次回退解码方式；
  - 仅用于非“从上至下”阅读模式。

- “快速翻页”，开启后左右区域将支持快速单击翻页，其余区域仍支持双击放大。
- “长按保存”，用于快速收藏单张图片。长按翻页区域即可保存当前图片，其位置随阅读方向变化。
- “保存后翻页”，开启后长按保存后将自动翻至下一页。
- “手动保存路径”，用于单独设定长按保存的目标目录。
- 长按保存成功后以图标提示；在提示消失前点击图标可撤销本次保存。
- “自动翻页”改为使用毫秒值，支持输入 `20 ~ 30000 ms`，或通过滑动条设置 `100 ~ 15000 ms`，默认 `2000 ms`。
- “快捷方式栏”，点击中部下方区域，与下方滑动条一起，在屏幕上方出现。包含多个以上设定在内的阅读相关快捷按钮。

### 订阅聚合

- “书签订阅”，合并所有已启用订阅的书签搜索结果，按 GID 去重后以发布时间排序。
- 在书签栏设置或 `设置 - Fork 额外功能 - 书签订阅` 中管理订阅。
- “全局订阅”，在书签订阅基础上额外合并 EH 网页自带订阅内容。
- “自动获取订阅更新”，自动获取未读画廊数量并在侧边栏中显示。
  - 可选择是否检查 EH 订阅或书签订阅；
  - 自动每小时检查一次，也可通过侧边栏“更新订阅”立即检查，并显示更新倒计时。
- 订阅页内长按画廊搜索其来源书签。
- 启动页支持“书签订阅”或“全局订阅”。

### 已下载画廊管理

- “下载标签连续浏览”，可在同一页面连续展示不同下载标签内的画廊；
  - 可通过下载列表菜单中的“切换列表模式”随时切换；
  - 标签标题显示画廊数量；点击标题可重命名标签，长按标签可直接发起对应画廊搜索。
- 下载列表界面右下角新增按钮“归类收纳”，可通过多选已下载画廊，根据关键词 (作者, Coser, 标题, 上传者) 进行分类并放入对应下载标签，标签支持`#注释`。
- 下载标签管理新增功能：多选、区间选择、批量删除、批量移动、排序、删除空标签。
- “删除本地不存在的画廊”，扫描并清理下载列表中目录缺失或空目录的记录。

### 画廊搜索

- 侧边栏提供“搜索语言项”按钮，可当前搜索条件中添加或删除语言标签并进行搜索，可在设置更改不同语言标签。
- 缩略图模式可在封面右下角显示已下载标识。
- 画廊搜索页右下角按键提供“画廊多选”模式，可批量下载或删除选中画廊。

### 画廊详情与预览

- “画廊预览立即跳转”，开启后详情页底部的预览入口将直接跳转到第二页的新内容。
- 详情页支持向左滑动快速进入画廊预览，并根据情况决定是否直接跳转至第二页。
- 画廊预览支持双指缩放，即时调整每行图片（缩略图）数量，最多 `8` 张。
- “作者”按钮，优先搜索第一个 `artist:` 或 `cosplayer:` 标签，不存在时尝试从标题括号内容提取关键词进行搜索。
- 右上角菜单支持第三方软件打开画廊图片和复制画廊本地路径。
- 浏览父画廊时直接一键获取所有父画廊，并标识已下载的父画廊。
