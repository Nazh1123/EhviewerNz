## 主要功能

### 图片浏览

- [“动图播放控制”](#动图播放控制)，为动态 WebP 和 GIF 提供播放/暂停、播放进度条、时间显示、倍速与顺序播放功能；
- [“漫画翻译”](#翻译与超分辨率)，支持本地 GGUF 模型，离线 ML Kit，OpenAI 兼容 API 途径。
- [“超分辨率”](#翻译与超分辨率)，使用 waifu2x 放大静态图片，支持 GPU / Vulkan 加速、倍率选择等。
- [“键位设置”](#键位设置)，支持多配置自定义单击、双击、长按动作及触摸区域尺寸；双击支持绑定为“无操作 (允许快速单击)”。
- [“阅读器滚动预览”](#阅读器滚动预览)，点击或拖动页码进度条浏览缩略图，点击预览图片后跳转。
- 可作为本地图片浏览器，打开图片文件并浏览同目录下其他图片，并保存历史记录。

### 画廊详情

- [“书签订阅”](#书签订阅)，合并所有订阅书签的搜索结果，在单一页面中以发布时间排序，并自动更新。
- [“画廊更新”](#画廊更新)，画廊可复用旧画廊内容 (基于画廊最初版本GID 和图片pToken) 进行更新，提供仅阅读更新途径。
- 预览页面支持左滑快速进入，页内支持双指缩放，即时调整每行图片(缩略图) 数量。
- “作者”按钮，搜索画廊[作者关键词](#关键词提取)；长按按钮可将完整标题拆解，以供用户选择组合进行搜索。
- [查看](#详细页) 画廊详细页更多操作功能。

### 画廊浏览

- “封面缩略图大小”与“预览缩略图大小”独立设置，支持按每行可显示数量调整。
- “显示已浏览画廊”，以分割线显示当前搜索条件的上次浏览位置。
- “精确评分筛选”，可替代网站的画廊评分筛选，支持输入`0.00 ~ 5.00`精确筛选，以及设置常驻最低评分过滤。
- “额外信息栏”，以缩略图模式(大)浏览时可在封面下方显示标题、发布时间、打码类型、下载标识、更新标识与阅读进度，可选色彩高亮。
- [查看](#画廊搜索) 画廊搜索页更多操作功能。

### 下载管理

- [“下载标签连续浏览”](#下载标签)，可在同一页面连续展示不同下载标签内的画廊，并提供标签管理功能。
- 已下载画廊搜索支持不区分大小写。
- 下载列表界面右下角新增按钮“归类收纳”，可通过多选已下载画廊，根据[作者关键词](#关键词提取)进行分类并放入对应下载标签，标签支持 `#注释`。
- “导入本地文件夹”，将本地文件夹内图片导入为画廊，并提供同步文件夹功能。

### 修复

- 修复上游版本中从画廊详情页返回下载列表后无法翻页的问题。
- 修复上游版本中点击应用图标进入应用时，可能异常进入上次页面的问题。
- 修复上游版本中特定情况中下载画廊不保存.ehviewer文件的问题。

## 功能详细说明

### 动图播放控制

- 为动态 WebP 和 GIF 提供新解码和控制播放方式，可进行播放/暂停、倍速、进度条拖动等。
- “长按快进”支持 `0.1x ~ 3.0x` 倍速播放。在屏幕下方动图控制区域长按激活快进，左右移动更改倍率，上滑可锁定当前倍率，松开恢复正常播放。
- 开启“顺序播放”后，动图结束时自动进入下一页。
- 动图播放卡顿时显示警告，可点击进行降级以减少卡顿：首次降低解码分辨率 (50%*50%)，再次回退原有解码路径。
- 竖直阅读方向仍使用原有解码路径。

### 翻译与超分辨率

- 点击阅读器上方快速按钮栏中按钮，开启或关闭翻译或超分辨率处理。
- 开启流程后在阅读器上方显示进度条浮窗，两种流程浮窗独立；点击浮窗可切换显示对应模式的结果图。
- 长按菜单含有两种流程的子菜单项，提供重新处理本页、处理完整画廊等按钮。
- 在当前页后，默认提前翻译后续 `2` 页，可设为 `0 ~ 6`(翻译)、`0 ~ 10`(超分) 页。
- 同一页同时需要翻译与超分时，先翻译、再超分；两种处理的预处理范围独立。
- 画廊整本翻译与超分任务按画廊排队，通知统一显示处理进度、失败页数和排队数量，并可停止当前画廊任务。
- 详情页右上角可提交整本翻译或超分任务。

#### 漫画翻译

- 在当前设备上进行 OCR 文字识别、去字、排版，翻译文本所用设备根据设置而定。
- 提供本地 GGUF、ML Kit 和 OpenAI 兼容 API 三种翻译方式；本地模型与 ML Kit 语言包准备完成后可离线使用。
- 在 `设置 - 翻译` 中选择翻译的方式、模型、语言、去字方式、预翻译页数。
- `设置 - 翻译 - 模型管理` 集中管理漫画识别模型、ML Kit 语言包和本地 GGUF，支持下载、校验、删除及漫画模型 / GGUF 文件导入；可保留多个 GGUF 并切换使用，App 提供 [Hy-MT2-1.8B-Q4_K_M](https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF) 和 [基于 HY-MT2-1.8B 的日译中漫画微调模型 Q4_K_M](https://huggingface.co/fumetodev/Hy-MT2-1.8B-JP-Manga-Finetune-chinese-zh-Hans-v1-GGUF) 下载途径作为预设。
- GGUF 导入支持“复制到应用私有目录”或“直接调用外部文件”。
- 翻译结果为透明 png 遮罩图片形式。

#### 超分辨率

- 使用 waifu2x 放大静态图片，支持 GPU / Vulkan 加速，提供速度优先、画质优先和仅 CPU 三种方式；GPU 不可用或失败时回退 CPU。
- 在 `设置 - 超分辨率` 中管理模型、放大倍率、预处理页数、结果图片质量、持久保存与缓存上限。
- 支持 `2× / 4× / 8× / 自动` 放大；“自动”从三种倍率中选择，使输出短边尽量达到 `1200px`。
- “结果图片质量”支持 `80 / 85 / 90 / 95 / 100` 与无损 WebP，默认 `95`，`100` 仍为有损压缩；编码受限时回退 PNG。

#### 处理结果

- 在 `设置 - 阅读` 中开启“显示已有结果”，通过画廊结果索引，在关闭自动翻译或超分时仍可显示已有结果。
- “导入目录内结果”扫描并导入当前画廊中已有的完整翻译和超分图片。
- 下载列表与详情页显示翻译、超分的完成页数和处理进度。
- 在下载列表中可通过右下角按钮查看原图、翻译与超分结果的数量和占用空间，并按类型删除结果。
- 分别支持选择是否将已下载画廊和导入的本地文件夹的结果图逐页保存至画廊文件夹下的 `_translated` 或 `_super_resolution` 子文件夹。

### 键位设置

- 新增 `设置 - 键位`，按三种阅读方向分别自定义 7 个触摸区域的单击、双击、长按动作，支持翻页、菜单、控制栏、缩放、保存图片等操作。
- 触摸区域尺寸支持拖动分界线或输入百分比调整。
- 键位支持多种配置，提供默认与推荐配置；阅读器快捷按钮支持单击循环切换配置，长按选择配置。
- 支持翻页、阅读设置菜单、控制栏、缩放、图片菜单、保存图片、“开启/关闭翻译”和“切换配置”等动作；将区域双击设为“无操作 (允许快速单击)”可实现快速单击。
- “屏幕切换手势”，当图片与当前屏幕方向不一致，可通过手势快速切换屏幕方向，切换后 `3` 秒内再次执行同一手势可切回；支持设置为上滑、下滑或关闭。

### 阅读器滚动预览

- 改变阅读器内原有的页码进度条机制：点击或拖动进度条，显示可横向滚动的缩略图预览，点击预览图片跳转至对应页面。
- 滚动预览在浏览在线画廊时使用网站缩略图；浏览已下载或已缓存的图片时如无网站缩略图，则使用原图降采样生成的缩略图。
- 在 `设置 - Fork 杂项 - 阅读` 中可关闭“阅读器滚动预览”，恢复原有进度条翻页方式。

### 画廊更新

- 画廊更新逻辑使用其最初版本画廊 GID(first_gid)作为版本链依据，复用最接近当前版本的旧画廊文件，在更新完成后删除所有旧画廊。
- “版本历史”展示画廊版本链列表，并标识其中已下载画廊。
- “更新日志”记录更新时间、新增页和删除页，支持浏览当前画廊的所有更新历史。
- “仅阅读更新”只浏览该次更新新增的页面，并同时显示更新页序号与原画廊页码。
- "查看更新历史记录"，在下载列表右上角更多菜单或左侧边栏进入，浏览按时间排序的所有画廊更新记录。
- “删除旧版本画廊”按钮，扫描拥有相同 first_gid 的画廊并保留可阅读的完整最新版本画廊，删除同版本链旧画廊。

### 书签订阅

- “书签订阅”，合并所有订阅书签的搜索结果，按 GID 去重后在单一页面中以发布时间排序。
- 在书签栏设置或长按侧边栏“书签订阅”管理订阅。
- “全局订阅”，在书签订阅基础上额外合并 EH 网页自带订阅内容。
- “自动获取订阅更新”，自动获取未读画廊数量并在侧边栏中显示；
  - 勾选自动检查 EH 订阅或书签订阅；
  - 自动检查间隔默认 `60` 分钟，也可通过侧边栏“更新订阅”立即检查，并显示更新倒计时。
  - 长按侧边栏“更新订阅”，可直接设置自动更新开关与更新间隔。
- 书签订阅支持将可合并的订阅条件合并搜索；手动检查更新时会复用已有搜索结果，减少重复请求。
- 长按画廊查看其来源订阅书签。
- 可设置"书签订阅"或"全局订阅"启动页。

### 保存图片

- 用于快速本地收藏单张图片。
- 在[键位设置](#键位设置)中提供“保存当前图片”“保存当前并下一页”和“保存上一页”操作选项。
- “手动保存路径”，用于设定长按保存的目标目录，支持“自定义”“默认”和“跟随下载路径”三种方式；跟随下载路径时保存至该目录下的 `_image` 文件夹。
- 保存成功后以图标提示，并区分普通保存、覆盖保存、上一页保存；在提示消失前点击图标可撤销本次保存。

### 下载标签

- “下载标签连续浏览”，可在同一页面连续展示不同下载标签内的画廊；
  - 可通过下载列表菜单中的“切换列表模式”切换；
  - 标签操作面板可重命名、搜索或同步标签 (长按)，也可展开或折叠标签内容 (单击)。
- 下载标签管理：多选、区间选择、批量删除、批量移动、排序、删除空标签；重命名为已有标签时可直接合并。

### 详细页

- 优先使用列表和本地已有信息展示详情页内容，避免加载时黑屏。
- 详细页支持删除画廊的本地文件。
- “回到最上方”按钮，在详情页可快速返回页面顶部。
- “画廊预览立即跳转”，开启后详情页底部的预览入口或向下滑动将直接跳转到第二页的新内容。
- 向左滑动快速进入画廊预览，并自动判断是否跳转第二页。
- 长按预览图放大显示(当预览图加载失败时，长按优先进行重载)。
- 右上角更多菜单提供：本地打开画廊、本地路径复制、本地占用体积。

### 画廊搜索

- 画廊搜索页支持长按快速下载：
    - 缩略图模式(大)且开启额外信息栏时，长按画廊右下角执行下载，长按左下角放大封面预览图；
    - 详细模式，长按画廊封面执行下载。
- “搜索预设标签”，支持在 `设置 - 搜索` 中配置两组标签(预设`语言`、`AI 生成`)，可通过按钮切换包含、普通、排除三种状态，如`l:"chinese"`, `""`, `-l:"chinese"`。
- “精确评分筛选”支持输入 `0.00 ~ 5.00` 的最低评分，最多两位小数；可设置“常驻筛选评分”作为每次搜索的默认筛选下限。
- 搜索输入时提供“更多搜索条件”按钮，可展开或收起搜索选项；修改同位置的“搜索”按钮可见性，以防两者被搜索候选项或输入法遮挡。
- 画廊搜索页右下角按键提供：
  - “仅已下载”模式，可在搜索与列表中筛选本地已下载和可更新画廊。
  - “画廊多选”模式，可批量下载或删除选中画廊。

### 关键词提取

- 用于"作者"按钮，以及下载画廊的“归类收纳”。
- 首先依次尝试提取画廊Tags中的`Artist:`, `Coser:`, `Group:`标签。
- 无可用Tag时尝试从画廊标题中获取：
  - 尝试提取画廊中括号`[]` `()`内文本，并忽略特定黑名单文本；
  - 无可用括号内文本时尝试获取标题的第一个单词。
- 全部失效时使用画廊上传者作为关键词。

### 历史记录

- `设置 - 历史` 集中管理浏览历史、阅读历史和画廊更新记录；侧边栏支持将历史入口合并为可展开的折叠菜单。
- “阅读历史”，默认开启，在进入阅读器时记录阅读来源、时间与进度，并按最近进入时间排序；仅浏览详情页不会产生阅读记录。
  - 同一画廊从详情页、下载列表、预览、画廊列表或“仅阅读更新”等不同入口进入时分别记录。点击记录按原进入方式重新阅读。
  - 可在 `设置 - 历史` 中关闭记录或调整保留数量，支持长按删除单条记录或通过菜单清空。
- 阅读历史与更新记录中，点击封面进入详情，点击其余区域继续阅读对应画廊或当次更新内容。

### 杂项

- “自动翻页”，支持设定毫秒值，支持输入 `20 ~ 30000 ms`，或通过滑动条设置 `100 ~ 15000 ms`。
- “使用本机时区”，默认按设备时区显示画廊上传时间等网站时间；关闭后使用 UTC。
- “删除本地不存在的画廊”，扫描并清理下载列表中目录缺失或空目录的记录。
- 书签管理界面支持重命名和查看书签原关键词。
- 应用更新可选择打开 Release 页面，或直接在应用内下载 APK 并安装。
