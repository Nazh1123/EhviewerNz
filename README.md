# EhViewerNz

EhViewerNz 是基于 [Ehviewer_CN_SXJ](https://github.com/xiaojieonly/Ehviewer_CN_SXJ) 的 Fork.

## Fork 功能

### 功能设置

- 设置菜单中为Fork各项功能加入自定义和开关设置。
- `设置 - Fork 额外功能` 集中提供对应同步设置，以供快速浏览。
- Fork 功能包含：
  - [快速保存](#图片浏览)、[双击放大](#图片浏览)、[自动翻页](#图片浏览)；
  - [书签订阅](#订阅聚合)、[全局订阅](#订阅聚合)、[额外启动页](#订阅聚合)；
  - [搜索语言项](#画廊浏览列表)、[下载标识](#画廊浏览列表)；
  - [提取作者](#画廊详情与预览)、[左滑预览](#画廊详情与预览)、[预览快速跳转](#画廊详情与预览)、[预览UI缩放](#画廊详情与预览)。

### 图片浏览

- “双击放大”，关闭后支持快速单击翻页，开启后恢复原逻辑 (双击可放大图片)。
- “快速保存”，阅读图片时可通过以下方式执行：
  - 长按屏幕两侧 `36%` 的翻页区域，位置会随阅读方向变化；
  - 点击屏幕左下方（`左侧 36%` × `底部 10%`）区域 (旧方案，仅作保留)。
- “保存后翻页”，可在快速保存成功后自动翻至下一页。
- “手动保存路径”，用于单独设定快速保存的目标目录。
- “自动翻页”改为使用毫秒值，支持输入 `20 ~ 30000 ms`，或通过滑动条设置 `100 ~ 15000 ms`，默认 `2000 ms`。

### 订阅聚合

- “书签订阅”，合并所有已启用订阅的书签搜索结果，按 GID 去重后以发布时间排序。
- 在书签栏设置或 `设置 - Fork 额外功能 - 书签订阅` 中管理订阅。
- “全局订阅”，在书签订阅基础上额外合并 EH 网页自带订阅内容。
- 长按画廊搜索其来源书签。
- 启动页支持“书签订阅”或“全局订阅”。

### 画廊浏览列表
- 侧边栏提供“搜索语言项”按钮，可当前搜索条件中添加或删除语言标签并立进行搜索，可在设置界面更改所应用的语言标签。
- 缩略图模式可在封面右下角显示已下载标识。
- 画廊列表支持多选，可批量下载或删除选中画廊。

### 画廊详情与预览

- “作者”按钮，优先搜索第一个 `artist:` 或 `cosplayer:` 标签，不存在时尝试从标题括号内容提取关键词进行搜索。
- 详情页支持向左滑动快速进入画廊预览。
- “画廊预览立即跳转”，开启后详情页底部的预览入口将直接跳转到第二页的新内容。
- 画廊预览支持双指缩放，即时调整每行图片数量，最多 `8` 张。
